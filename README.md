# TE Service Examples

Small example mods for the Twilit Essentials services.

- `src/stamina/` - drawing the bow drains stamina
- `src/collection/` - adds a Training Stick, a Patched Shield and Farmhand Clothes to the Collection screen
- `src/localization/` - adds a Demo to the language list
- `src/quick_access/` - adds a Heart Potion with 3 charges and a Fire Arrow (Bow + Lantern) to Quick Access, plus an own "Supplies" page with an Oil Refill
- `src/midna_flow/` - adds a Heal option to Midna's menu that can be turned on and off

The headers are in `include/twilit_essentials/`. Copy the one you need into your own mod.

Twilit Essentials has to be installed.
