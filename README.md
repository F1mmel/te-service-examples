# TE Service Examples

Small example mods for the Twilit Essentials services.

- `src/stamina/` - drawing the bow drains stamina
- `src/collection/` - adds a Training Stick to the Collection screen
- `src/localization/` - adds a Demo to the language list
- `src/quick_access/` - adds a Heart Potion with 3 charges to Quick Access

The headers are in `include/twilit_essentials/`. Copy the one you need into your own mod.

Twilit Essentials has to be installed.
